# Repo Improvement Plan — Single-Cycle RISC-V CPU

Based on a 3-agent review (core datapath, ALU sub-modules, build/tests/hygiene), with critical findings verified first-hand. Scope confirmed with user: **everything** (bugs + tests + build + docs); **keep ISA subset, document it**; **integrate add/sub into ALU**; **fix & integrate overflow.v**.

## Findings Summary

**Critical bugs:** `register_file.v:10` illegal `output reg` + `assign` (CPU doesn't compile); `single_cycle_cpu.v:43,101` instruction word wired where PC belongs (PC+4, branch targets broken); `single_cycle_cpu.v:47-50` IM program-load ports unconnected; ALU implements unsigned SLTU not SLT + latched stale `zero`; systemic latch inference (main_decoder, alu_decoder, mux31_32b, immediate_sign_extend, ALU default arms); memories byte-indexed into word arrays; `mul.v` accumulator never cleared between ops + non-synthesizable split-process reset.

**Test/build gaps:** 12 of 27 modules have no TB (incl. no top-level CPU test); failed assertions exit 0 (make "passes" on red); `mul_tb` missing from `alu_mods all`; `$HOME`-wide `find` project discovery in all Makefiles; AGENTS.md/README drift; empty `tools/slang/slang.f`.

## Phase 1 — Core correctness (get CPU compiling and runnable)

1. **`src/register_file.v`**: change `output reg` → ``output wire [`WIDTH-1:0]`` (lines 10,14-15). Replace `` `define REG_FILE_SIZE 32 `` with a `localparam`.
2. **`src/single_cycle_cpu.v`**: wire `.curr_instr_in(addr_instr_int)` for both `instruction_increment` (:43) and `branch_target` (:101). Rename those ports to `curr_pc_in` in their modules to kill the ambiguity. Connect IM's `prog_enable_in`, `instr_in`, `clk_in`; add `rstn_in` input port to the top and pass to PC.
3. **`src/program_counter.v`**: add active-low async reset: `always @(posedge clk_in or negedge rstn_in) if (!rstn_in) addr_out <= 0; else addr_out <= addr_in;` (matches `rstn` convention in mul.v).
4. **Word-address the memories**: `instruction_memory.v` index `addr_in[9:2]` (256 words); `data_memory.v` index `addr_in[10:2]` (512 entries). Derive slices from size parameters; move `` `INSTR_MEM_SIZE `` to a guarded define in `` `inc/common.vh `` (same for data mem). Change IM's blocking `=` to nonblocking `<=`.

Update for #4: Turn both `` `INSTR_MEM_SIZE `` and `` `DATA_MEM_SIZE `` to parameter and determine the new BUS_WIDTH paramter with $clog2.

## Phase 2 — Latch elimination + decoder correctness

5. **`src/ctrl_unit_mods/main_decoder.v`**: assign safe defaults to ALL outputs before the `case`; complete every arm (SW→res_src_sel, R_TYPE→imm_src_sel, JAL→alu_src_sel+alu_op, default→all-inactive so unknown opcodes write nothing). Fix `br_out = 1'b0` truncation (:27) and malformed `1'b01` literal (:61).
6. **`src/ctrl_unit_mods/alu_decoder.v`**: default `opctrl_out = 3'b000` before case; remove empty defaults (:23,:26); use `!` not `~` (:15). Reserve opctrl code comment noting future MUL collision (no ISA extension now).
7. **`src/cpu_mods/mux31_32b.v`**: ``default: s_out = {`WIDTH{1'b0}};``
8. **`src/immediate_sign_extend.v`**: default assignment before `case` (:18). Document supported-subset limitation (no U-type yet).
9. **Opcode defines hygiene**: move `` `define LW/SW/R_TYPE/BRANCH/JAL `` etc. into guarded `inc/riscv_opcodes.vh`; include from main_decoder, immediate_sign_extend, single_cycle_cpu.

## Phase 3 — ALU integration (user decision: integrate)

10. **`inc/alu.vh`**: add guarded ALU operation codes (`ALU_OP_ADD/SUB/AND/OR/LT`, 3-bit) replacing in-source defines; keep adder-impl selects. `arithmetic_logic_unit.v` and `alu_decoder.v` both include it (single source of truth).
11. **`src/arithmetic_logic_unit.v`** — rewrite:
    - Instantiate `add` (carry_in=0) and `sub`; mux `result_out` combinationally per `operation_control_in`; AND/OR stay behavioral.
    - LT: `` result_out = {{`WIDTH-1{1'b0}}, $signed(operand_a_in) < $signed(operand_b_in)}; `` (true RV32I SLT).
    - `zero`: combinational `` assign zero = (result_int == {`WIDTH{1'b0}}); `` — no latch.
    - Default arm assigns a defined value; no empty `default`.
    - New output port `overflow` fed by redesigned overflow module.
12. **`src/alu_mods/overflow.v`** — redesign interface: inputs `operand_a_in[31], operand_b_in[31], result_sign_in, is_subtract_in` (decoded control, NOT raw instruction fields); keep the two verified sign rules (add: signs equal ∧ result differs; sub via A+~B+1: signs differ ∧ result ≠ A sign). Fully assigned case/if — no latch. Instantiate inside ALU.
13. **`src/alu_mods/sub.v`**: rename misleading `borrow_out` → `carry_out` (raw carry; =1 iff a ≥ b unsigned). Align `sub_tb` and AGENTS.md wording.
14. **`src/alu_mods/add.v`**: `` `include "alu.vh" `` itself; restructure to `` `ifdef CARRY_LOOKAHEAD_ADDER_IMPL ... `else ...rca... `endif `` — exactly one impl always elaborated (no multi-driver / silent-z risk; 1364-2005 has no `elsif).
15. **`src/single_cycle_cpu.v`**: document supported ISA subset in a header comment (LW/SW/ADD/SUB/AND/OR/SLT/ADDI/BEQ/JAL). Leave ALU `overflow` output unconnected at top for now.

## Phase 4 — ALU sub-module standalone fixes (mul stays out of datapath)

16. **`src/alu_mods/mul.v`**: merge reset into one process `always @(posedge clk or negedge rstn)`; clear `accumulator` + `counter` on `set` (fixes back-to-back multiply corruption); register `operand_b_in` at `set` (inputs must be stable today — undocumented); `` {(2*`WIDTH){1'b0}} `` literal style.
17. **`src/alu_mods/mul_mods/shiftnadd_mod/shift_reg.v`**: single-process async-reset template for `busy`/`counter` (kills X-at-startup), nonblocking assignments throughout.
18. **`src/alu_mods/add_mods/cla_mod/modified_full_adder.v`**: `p_out = a_in | b_in;` (standard propagate; restores real lookahead property). Exhaustive CLA TBs must still pass (reviewer verified equivalence within current structure).

## Phase 5 — Assertion infra + TB conventions

19. **`inc/assert.vh`**: rewrite macros 1364-2005-portable (macro args never appear inside string literals): `assert_eq` prints binary, add `assert_eq_hex`/`assert_eq_dec`; increment a shared `error_count`; do NOT `$finish` on first failure unless fatal; final-summary convention below. Fix guard name → `ASSERT_VH`; drop `[INFO]` on failures.
20. **All TBs**: end with `$display("RESULT: %0s", (error_count == 0) ? "PASS" : "FAIL");` + `$finish`; fixed `$random(seed)`; consistent clock/reset template; `$dumpfile("<tb>.vcd")` in every TB. Migrate existing `assert_eq_fmt` call sites mechanically.
21. **Makefiles**: simulation rule gates success on the sentinel — run `vvp … > log`, fail if `[FAIL]`/missing `RESULT: PASS`. Remove blanket `.SILENT`.
