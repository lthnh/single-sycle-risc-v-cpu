`src/immediate_sign_extend.v` — combinational RISC-V immediate sign-extension unit. Takes a 32-bit instruction and a 2-bit `imm_src_sel_in`, outputs a sign-extended 32-bit immediate. Four formats: I-type (00), S-type (01), B-type (10), J-type (11).

## Design: Follow `sub_tb` Pattern

The `sub_tb` testbench is the closest analog: combinational DUT, reference model via continuous `assign`, `#1` delay, `assert_eq_fmt`. We adapt that pattern with a case-based reference model (since there's no simple Verilog operator for RISC-V sign extension).

### Testbench Structure

```
1. Includes + defines (SAMPLE_SIZE=100)
2. Module with DUT inputs as regs, output as wire
3. DUT instantiation
4. Clock generator in fork/join (includes $dumpvars) — kept for consistency
5. Reference model: combinational always block with case on imm_src_sel_in
6. Stimulus loop: 100 iterations × 4 types = 400 test cases
   - Each iteration: random curr_instr, loop over all 4 imm_src_sel values
   - After #1 delay: assert_eq_fmt(imm_ext_out, imm_ext_ref, %d)
7. Pass message + $finish
```

### Reference Model

A separate `always @*` block mirrors the DUT logic using a case statement. This is a "same-spec, different-implementation" reference — it encodes the same RISC-V sign-extension rules but as an independent implementation to catch copy-paste bugs.
